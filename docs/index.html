Exxos Easy GRUB Manager

APT repository for Exxos Easy GRUB Manager.

Install

curl -fsSL https://exxosuk.github.io/exxos-easy-grub-manager/exxos-easy-grub-manager.gpg.asc | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/exxos-easy-grub-manager.gpg
echo "deb https://exxosuk.github.io/exxos-easy-grub-manager stable main" | sudo tee /etc/apt/sources.list.d/exxos-easy-grub-manager.list
sudo apt update
sudo apt install exxos-easy-grub-manager
